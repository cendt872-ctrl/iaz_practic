
# Завдання 1: Збір даних із вебсайту (Web Scraping)

## Призначення скрипта

Скрипт `web_scraper.py` автоматично збирає заголовки новин із вебсайту за допомогою бібліотеки `BeautifulSoup`, фільтрує їх за ключовими словами та зберігає результати у файли `news_titles.csv` та `news_titles.json`.

## Як запустити

1. Встановіть залежності: `pip install requests beautifulsoup4`
2. Перейдіть у папку завдання: `cd data_collection_tasks/task_1_web_scraping`
3. Запустіть скрипт: `python web_scraper.py`
