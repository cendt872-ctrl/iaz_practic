# Завдання 3: Створення Google Форми (Google Apps Script)

## Призначення скрипта

Скрипт `create_form.gs` автоматично генерує Google Форму для оперативного збору даних ІАЗ ОУВ із полями: Електронна пошта (обов'язкове поле з валідацією формату), Ім'я, Дата та Відділ.
