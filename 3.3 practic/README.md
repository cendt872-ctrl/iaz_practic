# Звіт з практичної роботи 3.2 / 3.3: Аналіз набору даних `russia_losses_equipment`

## Мета роботи
Завантаження, очищення, описова статистика та кореляційний аналіз реального набору даних із платформою Kaggle (на прикладі щоденних втрат техніки у конфлікті).

## 1. Загальна характеристика набору даних
- **Загальна кількість записів (днів):** 1717
- **Кількість досліджуваних ознак (стовпців):** 20
- **Очищення:** Видалено дублікати, пропущені значення у числових показниках заповнено нулями відповідно до природи накопичувальних військових звітів.

## 2. Основна описова статистика
Для основних категорій техніки зафіксовано такі показники:
- **Танки (tank):** Середнє значення = 7386.4, Медіана = 8107.0, Максимум = 12456
- **ББМ (APC):** Середнє значення = 15001.1, Максимум = 25654
- **Артилерія (field artillery):** Середнє значення = 18458.0, Максимум = 52000
- **БпЛА (drone):** Середнє значення = 74546.0, Максимум = 598840

## 3. Зведені візуалізації (збережені у папці `plots/`)
1. `tank_losses_hist.png` — Гістограма розподілу втрат танків.

## 4. Висновки
- Кореляційний аналіз показує дуже високий ступінь взаємозв'язку між накопиченням втрат різних видів важкої техніки (коефіцієнти кореляції близькі до 1.0), що зумовлено кумулятивним характером щоденних звітів часового ряду.
- Використання бібліотек Pandas, NumPy, Matplotlib та Seaborn дозвочило повністю автоматизувати передобробку та графічний аналіз даних.
